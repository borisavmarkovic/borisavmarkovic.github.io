# Borisav Markovic — academic website

This is a simple static website made from two editable files:

- `index.html` contains the text and page structure.
- `styles.css` controls the appearance.

Open `index.html` in a text editor to update the biography, add links, or fill
the Work in Progress, Policy Reports, and Teaching sections. Comments in the
file mark the places to edit.

## Preview locally

Open `index.html` in a web browser. No installation or build step is required.

## Publish with GitHub Pages

1. Create a GitHub repository. For a personal homepage, name it
   `YOUR-USERNAME.github.io`; for a project page, choose any repository name.
2. Upload `index.html` and `styles.css` to the repository's top level.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.

GitHub will show the public address after deployment finishes.
